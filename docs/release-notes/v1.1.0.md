## 听译 Kikitori v1.1.0 —— 速度提升与视觉体验升级

本次更新全面优化了同传翻译性能与思考链抑制，显著缩短端到端时延；同时重构了悬浮字幕条视觉效果与单实例唤醒机制，并新增国内主流大模型服务商一键配置。

### 🚀 主要更新

#### 1. 翻译性能与极速同传优化（修复 Issue #1）
- **强力抑制思维链**：提示词首行注入最高优先级直接输出译文指令，彻底遏制推理模型输出思考草稿与 `<think>` 标签。
- **自动思考抑制参数**：OpenAI 兼容接口默认注入 `thinking: {"type": "disabled"}` 与 `reasoning_effort: "low"`，具备 400 参数自愈剔除降级机制。
- **翻译线程池扩容与防超时**：工作线程数由 2 扩容至 4，HTTP 翻译超时由 20s 缩短至合理实时的 8s，规避单句偶发延迟拖垮全局队列。
- **测速耗时诊断**：设置页提供带等级（⚡ 极速 / 正常 / 偏慢）的单次测速反馈。

#### 2. 字幕视觉与排版升级
- **系统级平滑动画**：字幕行挂载 `RepositionThemeTransition`，多行向上重排推进丝滑过渡，告别生硬闪跳。
- **双层深色立体文字投影（TextShadow）**：彻底解决字幕在复杂明亮背景、高光视频画面中发虚的问题，文字更锐利清晰。
- **快捷开关控制**：在悬浮字幕条右键菜单与「设置 → 样式」中均支持一键开关“文字阴影”。

#### 3. 国内主流大模型一键预设
- 在「设置 → 翻译」选择「自定义（OpenAI 兼容）」时，新增快捷预设下拉：
  - **SiliconFlow 硅基流动**（DeepSeek-V3 / Qwen2.5-72B）
  - **阿里云百炼 DashScope**（qwen-plus）
  - **智谱 AI 开放平台**（glm-4-flash）
  - **DeepSeek 官方平台**（deepseek-chat）
- 一键自动填入 Base URL 与模型名称，只需填写对应 API Key 即可使用；同时为 Ollama 提供常用模型快捷选择。

#### 4. 稳定性与生命周期修复
- **WinUI 3 unpackaged 崩溃防护**：修复免安装 unpackaged 模式下 `AppWindow.IsShownInSwitchers` 引发的 `NotImplementedException` 崩溃。
- **内核事件 1ms 跨进程单实例唤醒**：全面改用 Windows 内核 `EventWaitHandle`，双击启动在 1 毫秒内瞬间唤醒已有实例并置顶到最前台，彻底消除僵尸进程阻塞。
- **托盘异常容错防护**：增加托盘创建后台重试机制；当托盘不可用时关闭主窗口自动优雅退出，防止形成隐藏幽灵进程。
