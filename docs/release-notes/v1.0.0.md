## 听译 Kikitori v1.0.0 —— 首个版本

看日 V 直播听不懂？听译会实时识别电脑正在播放的声音，翻译成中文，显示成悬浮字幕。B 站网页、客户端、YouTube、本地视频都能用。

### 下载

| 文件 | 说明 |
|---|---|
| **Kikitori-1.0.0-setup.exe**（推荐） | 安装包，不需要管理员权限，自动创建开始菜单快捷方式，可在「设置 → 应用」中卸载 |
| **Kikitori-1.0.0-win-x64.zip** | 免安装版，解压后双击 `Kikitori.exe` |

> 程序没有数字签名，第一次运行时 Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可。

### 第一次使用

1. 第一次运行会自动下载显卡运行库（约 1.3GB）和语音识别模型（约 3GB），首页显示进度，只需下载一次。下载源默认「自动」，国内网络会自动选择镜像。
2. 在「翻译」页填写 DeepSeek API Key（在 https://platform.deepseek.com/api_keys 申请），点「测试连接」。
3. 打开直播，字幕就会出现在屏幕下方。字幕条可以拖动，右键可以切换语言、调整字号等。

### 系统要求

- Windows 10 1809 及以上 / Windows 11，64 位
- NVIDIA 显卡（建议显存 6GB 以上）。没有 N 卡可以在「语音识别」页把设备改成 CPU（会比较慢）。

### 主要功能

- 本地 Whisper large-v3 识别（显卡加速），一句话约 0.2 秒；说话过程中先显示原文草稿
- 翻译：DeepSeek（推荐）/ 本地 Ollama / 任意 OpenAI 兼容接口
- 说话语言：日 / 英 / 韩 / 中 / 俄 / 法 / 西 / 德 / 自动识别；翻译成：简体中文 / 繁體中文 / English / 日本語 / 한국어
- 置顶悬浮字幕条、托盘常驻、专有名词表、字幕自动记录

### 已知问题

- 背景音乐很大或者在唱歌时，偶尔会识别出没有意义的文字
- 目前只在 RTX 5070 Ti、100% 缩放、深色主题下测试过，其它环境欢迎反馈问题
